# PDF 批次列印工具

一個簡單的 Windows 小工具，可將指定資料夾內的所有 PDF 批次發送至印表機，支援自訂頁數與雙面列印。

---

## 📥 下載與使用（一般使用者）

> **完全不需要安裝任何東西！**

1. 點擊右側 **[Releases](../../releases/latest)** → 下載 `PDF批次列印工具.zip`
2. 解壓縮到任意資料夾
3. 雙擊 `PDF批次列印工具.exe`
4. 依序選擇印表機、PDF 資料夾、頁數、雙面設定，按下開始即可

> ✅ 僅支援 **Windows 10 / 11**

---

## 功能特色

- 📂 瀏覽選擇 PDF 所在資料夾
- 🖨️ 支援所有已安裝的印表機
- 📄 彈性頁數設定（全部 / 自訂如 `1-3,5`）
- 🔄 雙面列印（單面 / 長邊翻頁 / 短邊翻頁）
- ⚠️ 列印失敗時顯示錯誤清單
